# ⚡️ ربات تلگرام و وب‌اپلیکیشن OCR فارسی و انگلیسی (تبدیل رایگان عکس و PDF به متن و Word)
### 🚀 مجهز به موتور هوشمند جذب ممبر کانال تلگرام و فالوور اینستاگرام

این پروژه یک سیستم **کامل، حرفه‌ای و ۱۰۰٪ رایگان** برای تبدیل عکس‌های کتاب، جزوات دانشجویی، دست‌نویس‌ها و فایل‌های چندصفحه‌ای PDF به متن تایپ‌شده و فایل آماده‌ی Microsoft Word (`.docx`) است. 

این برنامه طوری مهندسی شده است که **بدون پرداخت حتی ۱ ریال هزینه برای API‌های گران‌قیمت خارجی** و با پردازش کاملاً محلی کار می‌کند؛ و در کنار آن دارای **پیشرفته‌ترین سیستم‌های جذب ممبر کانال تلگرام و افزایش بازدید و فالوور پیج اینستاگرام** است.

---

## 🌟 ویژگی‌های برجسته فنی (OCR & Document Processing)

1. **تبدیل عکس به متن (Photo to Text):**
   - استخراج متون فارسی و انگلیسی با موتور قدرتمند Tesseract.
   - فیلتر پیش‌پردازش تصویر با OpenCV شامل:
     - حذف سایه‌های دست و گوشی روی کاغذ با الگوریتم تطبیقی **CLAHE**.
     - صاف کردن خطوط و چرخش کجی عکس (Deskew / Auto-straightening).
     - حذف نویز دانه‌دانه کاغذ با فیلتر دوطرفه (Bilateral Filter).
2. **تبدیل فایل‌های PDF چند صفحه‌ای:**
   - پشتیبانی از فایل‌های سنگین درسی و دانشگاهی.
   - تفکیک صفحات و درج برچسب شماره صفحه در متن خروجی.
3. **خروجی مستقیم Microsoft Word (.docx) و Text (.txt):**
   - تولید فایل ورد استاندارد با **جهت‌گیری راست به چپ (RTL)**، فونت خوانای فارسی، تیتر و فاصله‌گذاری استاندارد پاراگراف‌ها.
4. **وب‌اپلیکیشن و مینی‌اپ تلگرام (Telegram Mini App):**
   - رابط کاربری مدرن با تم شیشه‌ای (Glassmorphism)، ریسپانسیو برای موبایل و دسکتاپ، با قابلیت کشیدن و رها کردن فایل (Drag & Drop).

## 🎯 موتور رشد و جذب ممبر و فالوور (Viral Growth Engine)

### ۱. سیستم جوین اجباری چند کاناله هوشمند (Multi-Channel Force-Join)
* کاربران برای پردازش هر عکس یا فایل، ابتدا باید در کانال‌های تلگرامی شما عضو شوند.
* دارای دکمه شیشه‌ای هدایت مستقیم و کلید «🔄 تأیید عضویت و ادامه».
* سیستم کش اختصاصی در حافظه (Memory Caching) برای جلوگیری از اسپم شدن ربات و ایجاد تأخیر در پاسخگویی.
* امکان **افزودن و حذف لحظه‌ای کانال‌ها از داخل پنل ادمین** بدون نیاز به دستکاری کد یا ری‌استارت سرور.

### ۲. استراتژی جذب فالوور و ویوی استوری اینستاگرام (Daily Story Code Lock)
* **قفل کدهای روزانه:** کاربران برای گرفتن اعتبار رایگان بیشتر یا دانلود نامحدود فایل‌های Word، نیاز به یک «کد مخفی» دارند.
* این کد روزانه در **استوری‌های پیج اینستاگرام شما** قرار داده می‌شود.
* **نتیجه:** هزاران کاربر ربات هر روز پیج اینستاگرام شما را باز می‌کنند، استوری‌ها را سین می‌زنند و نرخ تعامل (Engagement Rate) پیج شما را به شدت بالا می‌برند.
* ادمین می‌تواند کد هر روز را تنها با یک کلیک در پنل ادمین تلگرام تغییر دهد.

### ۳. سیستم رفرال و زیرمجموعه‌گیری ویروسی (Viral Referral)
* هر کاربر یک لینک اختصاصی دعوتی دارد (`https://t.me/Bot?start=ref_12345`).
* دکمه ارسال فوری بنر معرفی به همراه لینک در سوپرگروه‌ها و چت‌های دوستان.
* به ازای ورود هر عضو جدید، به معرف ۱۰ صفحه اعتبار اسکن رایگان داده می‌شود.

## 👑 پنل مدیریت پیشرفته ادمین (Admin Panel)

با ارسال دستور `/admin` در تلگرام:
* 📊 **آمار لحظه‌ای ربات:** تعداد کل کاربران، ورودی‌های امروز، کل فایل‌های اسکن شده، تعداد صفحات پردازش شده و وضعیت کانال‌ها.
* 📢 **ارسال همگانی (Broadcast):** ارسال متن، عکس و لینک به تمام کاربران ثبت‌نام شده با صف زمان‌بندی شده برای جلوگیری از بلاک شدن توسط تلگرام.
* 📢 **مدیریت کانال‌ها:** افزودن کانال اسپانسر، حذف کانال، مشاهده لیست کانال‌های فعال.
* 📸 **تنظیمات اینستاگرام:** تغییر آنی کد استوری روزانه و آدرس پیج.
* 🎁 **شارژ دستی اعتبار:** اضافه کردن اعتبار یا ارتقای کاربران به سطح ویژه (VIP).

## 🚀 روش راه‌اندازی سریع

### ۱. دریافت فایل‌ها و ساخت فایل تنظیمات (`.env`)
```bash
git clone https://github.com/AnishtayiN/persian-ocr-bot.git
cd persian-ocr-bot
cp .env.example .env
```

فایل `.env` را با یک ویرایشگر باز کنید و مقادیر زیر را قرار دهید:
* `BOT_TOKEN`: توکن ربات دریافتی از [BotFather@](https://t.me/BotFather)
* `ADMIN_IDS`: آیدی عددی تلگرام خودتان (برای ادمین شدن)
* `FORCE_JOIN_CHANNELS`: آیدی کانال شما (مثلاً `@MyChannel`)
* `INSTAGRAM_PAGE_URL`: آدرس پیج اینستاگرام شما

### ۲. اجرا با داکر (ساده‌ترین و پایدارترین روش)
```bash
docker compose up -d --build
```

### ۳. اجرای دستی با پایتون
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# اجرای همزمان ربات و وب‌اپلیکیشن
python run.py
```

وب‌اپلیکیشن و پیش‌نمایش زنده روی آدرس `http://localhost:8000` در دسترس خواهد بود.

## 📈 استراتژی طلایی برای وایرال کردن پیج و چنل

1. **ویدیوهای ریلز اینستاگرام (Reels):**  
   یک ویدیوی ۱۵ ثانیه‌ای ضبط کنید: با گوشی از یک صفحه کتاب یا جزوه دست‌نویس بدخط عکس بگیرید و بفرستید برای ربات، بعد فایل Word مرتب و تایپ‌شده را روی لپ‌تاپ باز کنید! با تیتر: *«دیگه لازم نیست جزوه تایپ کنی! لینک ربات تو بایو»*.
2. **استوری‌های مکمل:**  
   در استوری بنویسید: *«برای اینکه بتونید امروز تا ۵۰ صفحه رایگان فایل ورد بگیرید، کد امروز [OCR2026] رو توی ربات وارد کنید»*.
3. **گروه‌های دانشجویی:**  
   لینک ربات را در گروه‌های دانشگاهی و درسی به اشتراک بگذارید تا چرخه دعوت ویروسی شروع شود.
